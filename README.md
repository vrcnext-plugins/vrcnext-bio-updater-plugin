# Bio Updater

Keeps your VRChat bio, status, pronouns and bio links written from templates, on a schedule.

**Documentation:** <https://vrcnext-plugins.github.io/plugin-bio-updater.html>

```
https://github.com/vrcnext-plugins/vrcnext-bio-updater-plugin
```

Install by pasting the URL above into VRCNext's **Settings → Plugins**. Releases are signed by
